# Formation Lab — 3D フォーメーション対戦分析

サッカーのフォーメーション対戦（**4-2-3-1 / 4-3-3 / 3-4-2-1 / 3-3-2-2**）を 3D で俯瞰し、
ゾーンごとの人数・配置から**有利不利を自動分析**するツールです。

## 特徴
- **3D アニメーション**：ボールの循環に合わせて両チームの陣形がスライド・プレスする動きを再生
- **多彩なアングル**：俯瞰（真上）／中継カメラ／ゴール裏／コーナー のプリセット + ドラッグで自由回転・ズーム
- **有利不利の分析**：中盤中央の支配 / サイドの幅 / 最前線の駆け引き / プレス耐性 / ライン間の厚み を数値付きで提示
- **モバイル最適化**：縦画面ファースト、タッチ操作対応、セーフエリア考慮
- **文字がアニメーションに被らない**：3D ビューポートとテキスト（操作UI・分析）を明確に分離。HUD は端にドック、分析パネルは常にビューの下に配置

## 使い方
ビルド不要。`index.html` をブラウザで開くだけ（Three.js は CDN から読み込み）。

```
formation-3d/
├─ index.html
└─ assets/
   ├─ style.css       レイアウト（モバイル/デスクトップ）
   ├─ formations.js   配置データ + 相性分析エンジン
   └─ main.js         Three.js による 3D 描画・操作
```

HOME（青）／AWAY（赤）のフォーメーションを選ぶと、3D 表示と分析が即座に更新されます。
